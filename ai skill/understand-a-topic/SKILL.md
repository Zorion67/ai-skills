# Understand a Topic

用适合问题尺度的方式解释，让读者能定位主题、理解关键关系，并沿感兴趣的地方继续问。用户只给出一个领域名也可以开始。用本次请求和用户在当前对话中明确给出的背景决定范围、难度和例子。首次解释默认面向没有该领域背景的读者。

## 按问题选择讲法

| 输入 | 回答重点 |
| --- | --- |
| **大领域**，如「地理学」「医学」「数学」 | 用一两句话讲清它研究什么和典型问题。选适合该领域的分类视角，梳理主要分支，每个分支说明对象并给一个典型问题。用一两处关系说明分支怎样交叉或互相支撑。把通用方法和研究分支分开讲，遇到有多种分法的学科时说明这次采用的视角。默认约 3–5 分钟读完。 |
| **细分领域**，如「光电催化」「细胞学」 | 简要交代上一级学科和主题边界，再沿关键机制、过程或问题串起核心概念。用一个典型场景讲清这些概念如何配合，说明研究者用什么方法观察、测量或检验，以及结果能支持什么判断。细节随问题增减。 |
| **具体问题**，如「为什么越告诉自己别想一件事，反而越容易想到？」 | 先直接用白话回答，再按需要追到背后的机制、相关学科、理论和证据。用具体研究说明理论如何被检验，交代结论的适用条件。若有多种可信解释，说明它们分别能解释什么，以及什么证据可以区分。 |

先用通俗说法建立直觉，术语在首次出现时解释。用户问某个分支或理论时，从该处往下讲；用户要求速览时，保留主线。遇到有歧义的主题名，采用最贴近当次提问的解释并简短说明取法。若不同理解会明显改变答案且当前信息不足，问一个能区分它们的问题。

## 追溯理论和证据

理论名称能帮助理解时，把名字接在机制后面，并说明理论具体预测什么。用户问「谁提出的」或「最早是什么时候」时，查阅并链接能支撑归属的原始论文、著作或可靠学术史资料。按实际需要区分现象的早期记录、术语的提出、理论的正式表述和后续实验检验。史料只能支持较早记载时，说明查到的时间和范围。介绍较新、存疑或专业性强的研究结论时，核查相关来源并说明证据支持到哪一步。
