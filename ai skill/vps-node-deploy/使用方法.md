# 交给 Agent 怎么用

把整个 `vps-node-deploy` 文件夹交给可信 Agent，不要只传 SKILL.md，否则购买和部署参考文件会缺失。

直接对 Agent 说：

> 阅读 vps-node-deploy/SKILL.md 并按技能执行。我有自有 VPS，需要 Clash Verge、v2rayN、Shadowrocket 的节点配置、导入链接和二维码。请先检查已有服务，保留原配置，并实际验证连通性。Main IP 和 SSH 凭据通过私密方式提供，产物存到独立文件夹。

还没购买时说：

> 阅读这个技能包里的 references/buying-guide.md，带我核对 VPS 商品和购买流程；我自己完成付款，再提供开通信息。

支持 Codex 技能目录的环境，可把 `vps-node-deploy` 放进自己的 `~/.codex/skills/`，然后在新会话使用 `$vps-node-deploy`。不支持自动发现技能的 Agent 也可以直接读取整个文件夹。

Agent 需要具备文件读写、SSH/终端和必要网络权限。只会聊天、不能执行命令的 Agent 无法仅靠技能文件自动部署服务器；它应说明限制而不是声称已搭好。

本包不含任何真实 VPS 地址、账户密码或节点密钥。不要把自己收到的带密码邮件加入这个可转发包。购买教程以 DediRock 为例，不要求必须购买该平台，也不保证固定价格或线路速度。
