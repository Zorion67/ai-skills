# 补充：从购买 VPS 到交给 Agent

面向第一次买服务器的用户。以 DediRock 为示例，不表示推荐它适合所有网络。核对日期：2026-11-09。价格、库存、付款方式和界面会变，执行时重新访问官网；本文不含推荐返佣链接。

## 一、先买对产品

买的是 **Linux VPS / KVM VPS**，不是域名、共享网站空间或 VPN 软件。需要公网地址、SSH 管理权限，以及允许所需端口和用途的服务条款。

单人轻量代理可从 1 vCPU、1–2 GB 内存、约 10–20 GB 磁盘的配置开始比较，这只是资源规划参考，不是性能承诺。为初学者优先选择带独立公网 IPv4 的套餐；IPv6-only、NAT VPS 或 Windows VPS 会增加配置条件，别只看最低价格。

机房距离只是因素之一，同一机房对电信/联通/移动、Wi-Fi/蜂窝网络可能表现不同。能找到官方测试地址或 Looking Glass 时先测；没有从用户网络实测，就不要承诺“回国优化”“手机流量必通”或特定服务解锁。

## 二、在平台购买：DediRock 示例

1. 打开 [DediRock 官网](https://dedirock.com/)，从官网进入 [客户与商店门户](https://billing.dedirock.com/)，避免搜索广告里的仿冒站。
2. 在门户 Store/Browse Products 中查找 **LA KVM VPS、NY KVM VPS 或 PROMO VPS LA/NY**。LA 指洛杉矶，NY 指纽约类别。入口当前可以公开访问，登录和结算页面未在本教程中实际下单验证。
3. 打开商品详情，检查 CPU、内存、磁盘、公网 IPv4、月流量、端口速率、位置与虚拟化。不要把官网月付产品和促销年付产品混为一谈。
4. 选择可用计费周期。在配置/购物车页确认本次实付、续费价、税费、附加项目、自动续费和退款条件。历史案例的 9.88 美元不是当前保证价；若页面没有该价，不应按旧教程强行寻找或猜优惠码。
5. 注册或登录自己的账户，填真实可用邮箱和平台要求的真实账单信息。验证码、支付信息由本人完成；不要让 Agent 编造地址或替代身份核验。
6. 如果有系统选择，选受支持的 Debian 或 Ubuntu LTS Linux 镜像；由 Agent 后续确认具体版本。Hostname 是主机名称，不是购买域名，也不是 SSH 密码。没有系统选项时，开通后在管理控制台确认。
7. 核对订单后，由本人使用平台当前提供的支付方式付款。不要因为教程曾提过某种支付方式就认定现在一定支持。
8. 等待开通邮件，并在账户中查看服务状态。Invoice/Paid 表示账单已付，不自动代表机器已完成开通。Pending 时不要反复下单。
9. 在开通邮件或 Manage Services/对应 VPS 页面寻找 IP、SSH 登录方式和系统信息。页面标签可能变化；缺少密码时检查是否配置为 SSH 密钥登录，或使用官方控制台的密码设置/重置流程。不要把客户门户密码当 root 密码。

当前官网促销页列有 root 权限、KVM、公网 IPv4 等产品信息；门户可见上述商店分类。购买前仍以商品详情和结算页为准。[官方促销页](https://dedirock.com/promo/)、[官方客户门户](https://billing.dedirock.com/)

## 三、付款前逐项记下

| 项目 | 要记录的内容 |
| --- | --- |
| 价格 | 本次总额、币种、周期、续费价格 |
| 网络 | 月流量额度、出入站计数方式、重置日、超额处理 |
| 端口 | 标称速率；是否共享或存在公平使用限制 |
| 地址 | 是否包含独立公网 IPv4 |
| 管理 | root/sudo 权限、SSH、控制台、系统重装选项 |
| 服务 | 支持的用途、退款、到期与自动续费规则 |

服务商条款按套餐分配月度流量，超额处理与退款不能自行猜测；付款前阅读 [官方条款](https://dedirock.com/terms-of-services/)，以当时文本和订单为准。1 Gbps 是端口速率，2 TB 是流量额度，两者不是同一个指标。

## 四、拿到哪些信息就能开始

可私密提供给可信 Agent 的模板：

```text
请使用 vps-node-deploy 技能，先检查服务器已有服务，再部署节点。
Main IP: <自己的 VPS 公网 IP>
SSH 用户名: root
SSH 端口: 22（若不同则填写实际值）
认证: <通过当前环境的安全输入提供密码，或给出本机 SSH 密钥路径>
需要: Clash Verge 配置、v2rayN 链接、Shadowrocket 链接和二维码
输出文件夹: <希望保存的位置>
保留已有服务；未测通过的项目请明确标注。
```

如果邮件仅给 Main IP 和 Root Password，Agent 可先按 root/22 检查；不是保证无需其他条件。识别不清的截图字符需要确认。不要把包含密码的原邮件或截图放进可转发技能包。

服务商网站登录密码和 VPS root 密码通常用于不同入口。部署一般不需要支付卡、邮箱密码或服务商账户密码。

## 五、拿到交付物后怎样确认买的服务器真能用

1. 按说明导入自己设备的客户端，选中节点并启用代理。
2. 首先访问普通目标网站，再验证实际要用的应用。
3. iPhone 分别在 Wi-Fi、蜂窝网络上验证；记录运营商、节点名称、错误和时间。
4. 电脑成功而手机失败时，向 Agent 发脱敏截图；不要只发送“延迟 300 ms”作为连通证明。
5. 在服务商后台查看剩余流量和续费日期，保留本地配置及必要备份。

## 六、常见购买卡点

- 无货：等待补货或比较其他适合的商品，不承诺 Agent 能恢复库存。
- 已付款未开通：核对订单状态与官方通知，必要时本人提交工单。
- SSH 超时：先看服务是否 Running、IP 是否正确、SSH 端口及防火墙，不能直接归因密码错误。
- SSH 密码失败：核对用户名、大小写和是否复制空格；不要无限重试。
- 没有公网 IPv4：重新核对购买的是 IPv6-only/NAT 商品，确认可行方案后再处理，不贸然重复买。
- 不满意速度：先进行分段实测；不能保证退款，也不能用不停换协议替代线路验证。
